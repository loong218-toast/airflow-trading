# airflow-trading

This system is a Polars-based grid-search hyperparameter optimizer for time-series trading ML, built to safely process hundreds of millions of rows using strict streaming execution and minimal memory usage, running in Docker Compose with Airflow on Linux (cgroups v2) and scalable across local and cloud environments. All parameters, features, and combinations are defined in /opt/airflow/airflow-trading/run_config.json, with no hardcoded logic and no computation unless explicitly enabled and non-zero. Market data is read from the append-only /opt/airflow/airflow-trading/data_lake/base_data_full.parquet (5-minute candles, close price only), processed only within grid_start_date and grid_end_date, and evaluated in rolling sl_tp_interval_months windows (era_int). The grid search evaluates SL/TP and entry_lookback_h combinations, while MAs and stochastic indicators are precomputed per era or globally, cached, and reused. MA logic is controlled by a 4-bit ma_int mask (trend-following by default, inverted when ma_reversion is enabled), with signed MA gaps (ma_price_gap, a/b/c) aggregated by median. The system avoids silent failures, defensive fallbacks, .copy(), dropped NaNs, and broad try/except blocks. Multi-worker execution is conflict-free: each worker writes only its own files, merging occurs only in the final combine task, and cache.py handles read/write only. The first run populates caches for backtests and signals; subsequent runs reuse them for faster execution, producing millions of aggregated result rows (including balance %, drawdown filtering, and position stats) plus a full equity time-series table. The schema.py is single source of truth for most datatype parts.
