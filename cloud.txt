BATCH_SIZE: larger on cloud to reduce orchestration overhead.

COMBINE_BATCH_SIZE: large to reduce many small merges into master; cloud nodes can handle bigger chunks.

PARQUET_FLUSH_ROWS: larger so equity/stage flush happens less frequently (but each flush writes bigger files).

CACHE_FLUSH_ROWS / CACHE_MAX_INMEM_ROWS: raised so you keep more rows in memory before spilling (fewer tmp parts).

CACHE_MERGE_CHUNK_SIZE: larger chunk size for streaming merges (fewer intermediate chunk files).

PARALLEL_WORKERS and numba thread envs: increase to saturate CPU on cloud machines.
